```bash
export API_KEY=sk-xxxx          # 跟你要一个
```

### 2. 纯 curl（任何语言/agent 都能调）
```bash
curl -X POST http://jiayinghou-any9.devcloud.woa.com:9102/api/v1/video/analyze/upload \
  -H "Authorization: Bearer sk-xxxx" \
  -F "file=@/本机/视频.mp4" -F "language=zh" -F "include_audio=true"
```

### 3. 文件已在服务器上 → 直接给路径（原有接口）
```bash
curl -X POST .../api/v1/video/analyze \
  -H "Authorization: Bearer sk-xxxx" \
```
